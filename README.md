# Sru Codes Portfolio

Interactive portfolio for **Srustisri Panda (@sru-codes)** — software engineering, backend systems, and creative web development.

## Stack

React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · GSAP · Lenis

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm run build
```
